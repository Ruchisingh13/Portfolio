## 📌 Overview

A modern, responsive personal portfolio website built with **pure HTML, CSS, and JavaScript** — no frameworks needed. Designed with a **trending 2025/2026 dark glassmorphism aesthetic** featuring animated particle backgrounds, smooth scroll effects, and interactive UI components.

**Live Demo:** Open `index.html` locally or serve with Python HTTP server.

---

## ✨ Features

- 🌊 **Animated Particle Canvas** — Dynamic floating particles with connected lines
- 🖱️ **Custom Cursor Glow** — Radial gradient follows the mouse
- ⌨️ **Typewriter Effect** — Auto-typing phrases in the hero section
- 🃏 **3D Project Card Tilt** — Cards tilt on mouse hover
- 📈 **Animated Stat Counters** — Numbers count up on scroll into view
- 🔁 **Scroll Reveal Animations** — Elements fade in as you scroll
- 📱 **Fully Responsive** — Works on desktop, tablet, and mobile
- 🍔 **Hamburger Menu** — Mobile-friendly navigation
- 📧 **Contact Form** — Opens default email client with pre-filled details
- 💜 **Glassmorphism Design** — Frosted glass cards with purple/cyan glow theme

## 🚀 How to Run

### Option 1 — Python HTTP Server (Recommended)
```bash
cd Ruchi_Portfolio
python -m http.server 5500
```
Then open: **http://localhost:5500**

### Option 2 — Open Directly
Just double-click `index.html` to open in your browser.

### Option 3 — VS Code Live Server
Install the **Live Server** extension → Right-click `index.html` → **Open with Live Server**
